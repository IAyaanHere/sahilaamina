# Resource Manifest

## Core Files
- `index.html`: Entry point for the invitation.
- `bismillah.mp3`: The main background audio track.
- `favicon.svg`: SVG icon for the site.

## CSS (`assets/css/`)
- `styles.css`: Main stylesheet with relative font and asset references.
- `fonts.css`: Locally mapped Google Fonts.

## JavaScript (`assets/js/`)
- `config.js`: Central configuration for details, theme, and media.
- `app.js`: Interactive logic, patched to prioritize `shortName` and force mute the background video.

## Fonts (`assets/fonts/`)
- Locally downloaded `.woff2` font files for 'Allura', 'Cormorant Garamond', 'DM Sans', 'Noto Naskh Arabic', and 'Cormorant Infant'.

## Media (`media/` & `assets/images/`)
- `media/intro-placeholder.mp4`: Background looping video.
- `media/intro-placeholder.webp`: Poster fallback image.
- `media/gallery/*.webp`: Pre-wedding gallery images.
- `assets/images/floral-divider.webp`: Decorative dividers.
- `assets/images/scratch-frame.webp`: Interactive scratch-card frame.
